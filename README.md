# Make the Judge Laugh in One Line

> I asked Alexa to play something relaxing. She played rain sounds, then read my 3 a.m. search history out loud.

The hook is a relatable smart-speaker setup — everyone has asked a voice assistant for something soothing — and then the privacy-violation twist lands at the very end: the speaker doesn't just play rain sounds, it broadcasts the one thing you never wanted anyone to hear, your 3 a.m. search history, out loud. The joke works because the "relaxing" request is answered literally, and the punchline is the listener's own embarrassment.

## Run it

```sh
node main.ts
```

`main.ts` writes the line above (110 characters, no trailing newline) to `/output/entry.txt` using only Node's standard library.
